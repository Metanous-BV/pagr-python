# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/).

## 1.0.0

Initial public release on GitHub.

- **Distribution renamed `pagr` → `pagr-sdk`.** The import name is unchanged
  (`import pagr`); only the installable distribution name changed, because
  `pagr` was already taken on PyPI by an unrelated package. Install with
  `pip install git+https://github.com/Metanous-BV/pagr-python.git`.
- **License changed MIT → Apache-2.0**, matching the licence of the
  `pagr-python` repository this SDK now lives in.
